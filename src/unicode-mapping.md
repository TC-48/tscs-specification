# TSCS to Unicode Mapping

This page provides a direct translation mapping from the Ternary Standard Character Set (TSCS) to unicode equivalents.

## Control Codes

| Code   | Decimal | Mnemonic | Name             | Unicode Code Point | Unicode Glyph |
|:-------|:--------|:---------|:-----------------|:-------------------|:-------------:|
| 000000 | 0       | NUL      | Null             | `U+0000`           |      `␀`      |
| 000001 | 1       | BEL      | Bell             | `U+0007`           |      `␇`      |
| 000002 | 2       | BS       | Backspace        | `U+0008`           |      `␈`      |
| 000010 | 3       | TAB      | Horizontal Tab   | `U+0009`           |      `␉`      |
| 000011 | 4       | EOL      | End of Line      | `U+000A`           |      `␊`      |
| 000012 | 5       | CR       | Carriage Return  | `U+000D`           |      `␍`      |
| 000020 | 6       | ESC      | Escape           | `U+001B`           |      `␛`      |
| 000021 | 7       | DEL      | Delete           | `U+007F`           |      `␡`      |
| 000022 | 8       | EOF      | End of File      | `U+001A`           |      `␚`      |
| 000100 | 9       | RS       | Record Separator | `U+001E`           |      `␞`      |
| 000101 | 10      | US       | Unit Separator   | `U+001F`           |      `␟`      |
